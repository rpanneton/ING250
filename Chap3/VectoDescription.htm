Vectorisation – description

Matlab est un langage de programmation qui utilise des matrices et des vecteurs comme données élémentaires et il est spécialement conçu pour effectuer des calculs sur ce type de données.

La vectorisation consiste à convertir des boucles comptées for en opérations vectorielles équivalentes. Elle comporte deux avantages :

  • le code est plus concis,
  • le programme tourne plus rapidement, car il tire profit des algorithmes d'optimisation de Matlab.

Cette section présente les opérateurs Matlab permettant de générer implicitement des boucles pour effectuer des calculs.

Opération pouvant être vectorisée
Une opération peut être vectorisée lorsqu'elle contient une boucle for et s'applique successivement à des éléments entre 2 tableaux, ou entre 1 tableau et un scalaire. Matlab est conçu pour tirer profit de l'aspect matriciel ou vectoriel des données.

Exemple 1 – constituer un vecteur

Calculer 4001 valeurs de 3 sin (θ) entre 0° et 400° .

Méthode traditionnelle

i = 0;
for theta = 0:0.1:400
   i = i + 1;
   y(i) = 3*sind(theta);
end

Version vectorisée

theta = 0:0.1:400; % opérateur deux points (:)
y = 3*sind(theta);

Le calcul de y est plus rapide et Matlab est conçu pour être utilisé de cette façon.

Autre version vectorisée

theta = linspace(0,400,4001); % fonction linspace
y = 3*sind(theta);

Méthode traditionnelle

X = [10, 20, 30, 40];
Y = [6, 2, 7, 3];
for i = 1:4
   XY(i) = X(i)*Y(i)
end

Version vectorisée

XY = X.*Y

Versions antérieures de Matlab

  • Matlab 6.1 - Il est nécessaire d'écrire une expression vectorisée pour tirer profit de l'augmentation de performance.
  • Matlab 6.5 et suivantes - Le logiciel est capable de reconnaître que la boucle comptée devrait être vectorisée. Matlab effectue alors automatiquement la vectorisation sans qu'il soit nécessaire d'écrire l'instruction vectorisée.
