  • Somme et moyenne avec une boucle
Somme = 0;
for i = 1:length(Dernieres)
   Somme = Somme + Dernieres(i);
end
Somme, Moyenne = Somme/length(Dernieres)

Somme =
        1258
Moyenne =
       209.67

La fonction length permet d'obtenir le nombre exact d'éléments de Dernieres, peu importe le choix initial. L'utilisation du nombre 5 rendrait le programme moins robuste.

combien=0; % compteur

   end
