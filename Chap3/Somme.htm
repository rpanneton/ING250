Sommation des éléments d'un vecteur X

Objectif : réaliser la sommation en manipulant les indices du vecteur.

  • Écrire d'abord la variable
    X = [41, 3, 19, 57, 23, 7, 31, 47, 11, 53, 5, 13, 29, 37, 43, 61]
  • Déterminer la taille à l'aide de la fonction length, applicable à un vecteur (colonne) ou à une matrice d'une rangée (vecteur rangée)
    n = length(X)

Procédure à suivre, X et n étant connus


Le symbole de sommation suppose habituellement l'utilisation d'une boucle comptée. 

  • étape 1
    • Écrire la boucle nécessaire et faire afficher seulement les indices requis. Dans l'exemple, l'indice  i fait varier la boucle de 1 à n.
  • étape 2
    • Afficher individuellement chacun des éléments du tableau, exemple X(i).
  • étape 3
    • Effectuer ensuite l'opération requise. Pour une sommation, l'initialisation du sommateur doit précéder immédiatement l'instruction for.
    • Afficher le résultat à chacun des cycles de la boucle. Si cela va trop vite, utiliser l'instruction pause qui arrête l'exécution; il faut appuyer sur {Entrée} pour continuer.
  • étape 4
    • Faire cesser les affichages (et enlever l'instruction pause).
Étape 1
for i = 1:n
   i
end
 
Étape 2
for i = 1:n
   i
   X(i)
end
 
Étape 3
Somme = 0
for i = 1:n
   i
   X(i)
   Somme=Somme+X(i)
   pause
end
 
Étape 4
Somme = 0;
for i = 1:n
   Somme=Somme+X(i);
end

Calcul de la moyenne
Diviser la somme par n à la fin du programme.

clear
X = [41, 3, 19, 57, 23, 7, 31,...
     47, 11, 53, 5, 13, 29, 37, 43, 61]
n = length(X)
Somme = 0;
for i = 1:n
   Somme = Somme+X(i);
end
moyenne = somme/n

% Rappel:
%  Une ligne précédée du symbole %
%  est un commentaire.
% --->  ...   <---
% Une ligne terminée par trois points
% indique que l'instruction se poursuit
% à la ligne suivante.

Écueils parmi les plus courants

  • Utilisation d'une variable temporaire inutile : 
o   Somme = 0;
o   for i = 1:n
o      N = X(i);
o      Somme = Somme+N;
o   end
o   moyenne = somme/n
    • La variable temporaire est inutile. De plus, les noms de variables n et N qui ne diffèrent que par une minuscule et une majuscule sont une source possible d'erreur.
    • Évaluation : il y a cinq lignes efficaces, dont une ligne est inutile, total = 4/5.
  • Utilisation de constantes : au lieu d'utiliser n pour contrôler la boucle, on utilise la valeur numérique correspondante, par exemple 16 pour la boucle ou pour le calcul de la moyenne.
    • C'est une mauvaise stratégie :
      • Cela réduit la portée du programme.
      • Si des valeurs sont ajoutées ou enlevées à X, le programme n'est plus applicable. Il faut rechercher toutes les valeurs de 16 et les modifier.
      • C'est facile pour un petit programme, mais c'est une procédure plus longue et plus risquée pour un gros programme.
    • Évaluation : il y a cinq lignes efficaces, dont deux lignes sont fautives; total = 3/5.
  • Calcul de la moyenne dans la boucle, exemple : 
o   Somme = 0;
o   for i = 1:n
o      Somme = Somme+X(i);
o   moyenne = somme/n
o   end
    • Constater que le calcul est faux (n-1) fois
    • On effectue (n-1) calculs pour rien.
    • Évaluation :
      • Effacer une ligne.
      • La replacer au bon endroit.
      • Total : 2 modifications, donc 3/5.
