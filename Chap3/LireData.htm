Pendant la mise au point d'un programme, il arrive que l'on doive écrire plusieurs fois les mêmes données au clavier. Or, l'utilisation de tableaux dans un programme suppose une quantité importante de données que l'on voudrait éviter d'écrire à répétition au clavier.

Cette section explique comment lire et créer des fichiers de données. Les fichiers proposés sont contenus dans le répertoire Chap3\Scripts. Les copier dans le répertoire de travail.

Lire un fichier de données ASCII – load

Pour éviter d'entrer directement les données dans la fenêtre Matlab, utiliser des fichiers ASCII pour contenir ces données. L'instruction load permet de les lire.

Contexte - Le fichier Distance.dat contient les distances parcourues en cm par de minuscules véhicules expérimentaux en nanotechnologie.

Il serait ennuyeux d'écrire à nouveau ces données afin de les traiter, ce qui pourrait de plus entraîner des erreurs. L'instruction load permet de lire automatiquement l'ensemble des données du fichier afin de constituer un tableau, soit un vecteur colonne dans l'exemple proposé ci-dessus :

L'instruction load propose deux méthodes de lecture.

  1. load Distance.dat
    • Le nom du fichier est écrit après le mot load.
    • Le fichier est lu au complet et Matlab génère un tableau appelé Distance.
    • Le nom du fichier est dépouillé de son extension.
    • Le nom de la variable Matlab générée respecte l'utilisation des minuscules et des majuscules. Windows n'en tient pas compte.
o    Exemple :
o    >> clear
o    >> load distance.dat
o    >> load DISTANCE.dat
o             % Noter : aucun écho n'est produit
o             % malgré l'absence du point-virgule.
o    >> whos
o      Name       Size  Bytes  Class
o      DISTANCE   27x1   216  double array
o      distance   27x1   216  double array
  1. A = load('Distance.dat')
    • Le nom du fichier est écrit entre apostrophes et constitue l'argument de la fonction.
    • La fonction retourne des valeurs qui sont les données contenues dans le fichier.
    • Il faut attribuer ces valeurs à une variable pour les utiliser ultérieurement.
    • Ainsi, la variable A devient un tableau contenant les données du fichier. 
o    Exemple :
o    >> clear
o    >> A=load('Distance.dat');
o    >> L=length(A)
o    L =
o        27
o    >> Mat=load('Acier.dat');
o    >> [Rang,Colonne]=size(Mat)
o    Rang =
o       512
o    Colonne =
o         2

Lire un fichier Excel  – xlsread, readmatrix

Attention : Dans les nouvelles versions de Matlab, il est suggéré d’utiliser readmatrix

Pour lire des données numériques, il suffit de substituer xlsread (readmatrix) à l'instruction load, par exemple :

>> clear
>> D1 = load('Distance.dat');
>> D2 = xlsread('Distance.xls');
>> D3 = readmatrix('Distance.xls');
>> Booleen12 = all(D1==D2)
Booleen1 =
  logical
   1
>> Booleen13 = all(D1==D3)
Booleen2 =
  logical
   1
 
>> whos
  Name     Size  Bytes  Class
  Booleen1 1x1      1  logical
  Booleen2 1x1      1  logical
  D1       27x1    216  double
  D2       27x1    216  double
  D3       27x1    216  double
