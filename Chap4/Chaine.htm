Les chaînes de caractères

Objectif : être capable de manipuler les éléments des chaînes de caractères (ou vecteurs de caractères).

  • Représentation dans la mémoire de l'ordinateur
  • fcanf - lecture d'un fichier de caractères
  • textread - lecture d'un fichier de différents types de données
  • fgetl - lecture ligne à ligne d'un fichier de différents types de données

Représentation dans la mémoire de l'ordinateur

Le type de base chaîne de caractères se trouve dans la plupart des logiciels de programmation. Une chaîne est une vecteur dont les éléments sont des caractères.

Les caractères sont conservés sous la forme de nombres entiers dans la mémoire de l'ordinateur.

>> 'Bonjour !' + 0
ans = 66 111 110 106 111 117 114 32 33
>> 'B'==66
ans = 1
>> 'o'== 111
ans = 1
>> 'n'== 110
ans = 1

Les codes de 1 à 127 représentent les caractères appelés ASCII. Windows utilise des codes de 1 à 255 pour représenter des caractères appelés ANSI. Les 127 premiers correspondent aux codes ASCII.

Matlab possède une bibliothèque de fonctions pour traiter les caractères :

>> doc strfun

char - Create character array (string).
double - Convert string to numeric character codes.
cellstr - Create cell array of strings from character array.
blanks - String of blanks.
deblank - Remove trailing blanks.
eval - Execute string with MATLAB expression.
etc.

fscanf - lecture d'un fichier de caractères -

  • La fonction load est appropriée pour lire des fichiers ne contenant que des nombres.
  • La fonction fscanf permet de lire le contenu d'un fichier comme une longue chaîne de caractères.
    • C'est une fonction qui ressemble à fprintf.
    • On peut lire également des données numériques, mais nous allons nous limiter à la lecture de fichiers contenant du texte.

Utilisation typique de fscanf

fid = open('Nom_du_fichier','r');
A = fscanf(où,comment);

  • où : no de fichier (correspond à fid ci-haut)
    • open ouvre le fichier appelé Nom_de_fichier en lecture seulement ('r') et lui attribue un numéro.
    • fid obtient ce numéro.
  • comment : le format de lecture. On utilise des caractères dans cette présentation, %c.
  • A contient la chaîne de caractères lus.

Exemple de lecture

% Ch_fscan.m  Lire un fichier
%    comme une grande chaîne.
clear; clc
fclose('all'); % Ferme tous les fichiers.
fid=fopen('Sommeil.txt','r');
Texte=fscanf(fid,'%c');
Auteure=Texte(1820:1848)
fclose(fid);
% Compte le nombre de lettres e dans Texte
NombreDeLettre_e=0;
for i=1:length(Texte)
   if(Texte(i)=='e')
      NombreDeLettre_e=NombreDeLettre_e+1;
   end
end
fprintf(1,'%s %d\n',...
   'Nombre de caractères « e » :',...
   NombreDeLettre_e);

Résultat :

Auteure =
Lisa Lipman, Associated Press
Nombre de caractères « e » : 220

textread - lecture d'un fichier de différents types de données

La fonction textread permet de lire facilement des fichiers où des données caractères et numériques sont bien formulées, c'est-à-dire lorsque les données sont alignées en colonnes et séparées par des virgules ou des espaces. Il suffit alors de spécifier un format correspondant au type de données à lire.
Exemple :

Sirius   8.7 -1.42
Altair  16.0  0.77
Pollux  33.0  1.16
Becrux 500.0  1.28
Castor  47.0  1.58
Adhara 330.0  1.63
Alioth  49.0  1.68
Shaula 200.0  1.71
Alkaid 190.0  1.91
Alhena  78.0  1.92
 colonne 1 - caractères,
nom, sans apostrophes

colonne 2 - nombre,
distance, années-lunières

colonne 3 - nombre,
magnitude.
  • [quoi] = textread('où', 'comment']
    • quoi : nom du vecteur pour chacune des colonnes,
    • où : nom du fichier à lire,
    • comment : indique le type de données à lire. Le format peut comprendre la largeur du champ. Les formats les plus utiles sont
      • %c - caractère, le champ ou nombre de caractères est requis.
      • %n - numérique, le champ est souvent superflu.

Exemple (fichier Texte_lu.m) :

>> [nom,distance,magnitude] = ...
 textread('Etoile.dat','%6c %n %n');
>> whos
  Name      Size Bytes  Class
  distance  10x1    80  double
  magnitude 10x1    80  double
  nom       10x6   120  char
 
'%6c%n%n'
%6c - 6 caractères pour nom
%n  - un nombre pour distance
%n  - un nombre pour magnitude

fgetl - lecture ligne à ligne d'un fichier de différents types de données

  • fgetl - Lecture ligne par ligne
  • Détection de la fin du fichier

Supposer qu'il faut lire un très long fichier, et que l'analyse doit s'effectuer ligne par ligne. Les fonctions textread et fscanf effectueraient la lecture du fichier complet en mémoire, ce qui pourrait ne pas être approprié. Solution alternative : fgetl

Lecture ligne par ligne - fonction fgetl

Cette opération est plus complexe que la lecture par textread.

Exemple : lire la première ligne du fichier Etoile.dat.

  • %Fichier Etoile3.m
clear
fid=fopen('Etoile.dat','r');
Ligne = fgetl(fid);
fclose(fid);
Nombre_de_caracteres=length(Ligne)
%Arrangement permettant de repérer
% la position des caractères.
Ligne
disp('----+----+----+----+')
%Conversion d'une chaîne en nombre
%   (string to number).
Etoile=Ligne(1:6);
Distance = str2num(Ligne(8:12));
Magnitude = str2num(Ligne(14:18));
fprintf('Étoile : %s\nDistance :%5.1f\nMagnitude :%6.2f\n',...
     Etoile,Distance,Magnitude);

Résultat :

  • Nombre_de_caracteres =
18
Ligne =
Sirius 8.7 -1.42
----+----+----+----+
Étoile : Sirius
Distance : 8.7
Magnitude : -1.42
    • La lecture s'effectue sous la forme d'une ligne de caractères.
    • Il faut manipuler le contenu pour en extraire les informations souhaitées.

Détection de la fin du fichier

On peut ainsi lire successivement toutes les lignes du fichier. Mais que se passe-t-il à la fin du fichier ? 

Lorsque Matlab détecte la fin du fichier, il indique {-1} comme donnée, ce qui permet de terminer la lecture.

  • %Fichier etoile4.m
clear 
disp('Début de la lecture :');
fid=fopen('Etoile.dat','r');
Ligne = fgetl(fid);
j=0;
while(Ligne ~= -1)
   j=j+1;
   Etoile(j,:) = Ligne(1:6);
   Distance(j) = str2num(Ligne(8:12));
   Magnitude(j) = str2num(Ligne(14:18));   
   Ligne = fgetl(fid);
   fprintf('%d, ',j);
end
fclose(fid);
fprintf('fin.\n\n')

for i=1:j
   fprintf('%s %5.1f %5.2f\n',...
      Etoile(i,:),Distance(i),Magnitude(i));
end
