Écriture de données dans un fichier ASCII (fopen, fprintf, fclose)

La fonction fprintf permet également d'écrire directement dans un fichier. Il suffit de spécifier le nom du fichier et de modifier légèrement le format d'écriture.

Terminer une ligne
par \r\n

Il faut modifier légèrement le format d'écriture, car, le symbole généré par \n (nouvelle ligne) n'entraîne pas automatiquement le passage au début de la ligne suivante dans un fichier. Il faut effectuer un retour à la ligne en ajoutant le caractère \r (retour au début de la ligne) avant le caractère \n. Le code \r\n signifie donc retour au début de la ligne et nouvelle ligne.

Utiliser fopen(...,'wt')

Ouvrir le fichier en mode wt, qui se traduit par write text. Matlab génère alors automatiquement les caractères de fin de ligne afin de rendre le fichier compatible avec d'autres applications qui utilisent des fichiers de texte bien formulés.

Exemple :

% Fichier Etoile2.m
clear; clc;
Etoile0 % données
disp('Écriture traditionnelle dans un fichier')
disp('Voir ÉtoileTrad.dat')
n=length(Distance);
fid=fopen('EtoileTrad.dat','w');
% w (write): pour l'écriture.
for i=1:n
   fprintf(fid,'%2.2d %s %5.1f %5.2f\r\n',...
      i,Etoile(i,:),Distance(i),Magnitude(i));
end
fclose(fid);

disp('------------------------------')
disp('     Écriture à l''écran')
disp('------------------------------')
for i=1:n
   fprintf('%2.2d %s %5.1f %5.2f\n',...
      i,Etoile(i,:),Distance(i),Magnitude(i));
end
disp('------------------------------')

disp('Écriture avec un même format dans EtoileNonOk.dat')
fid=fopen('EtoileNonOk.dat','w');
% w (write): pour l'écriture.
for i=1:n
   fprintf(fid,'%2.2d %s %5.1f %5.2f\n',...
      i,Etoile(i,:),Distance(i),Magnitude(i));
end
fclose(fid);

disp('Écriture avec argument wt : EtoileAvecArgWt.dat')
fid=fopen('EtoileAvecArgWt.dat','wt');
% w (write): pour l'écriture.
for i=1:n
   fprintf(fid,'%2.2d %s %5.1f %5.2f\n',...
      i,Etoile(i,:),Distance(i),Magnitude(i));
end
fclose(fid);

Résultat :

fopen

fid = fopen(Nom_du_fichier,'permission')

Cette instruction ouvre un fichier pour la lecture ou l'écriture. Matlab retourne alors un nombre entier utilisable par une fonction de lecture ou d'écriture comme fprintf.

  • Le Nom_du_fichier est une constante ou une variable caractère.
  • La chaîne 'permission' peut prendre plusieurs valeurs dont :
    • 'r' {read} ouvre le fichier pour la lecture ;
    • 'w' {write} ouvre un nouveau fichier pour l'écriture. Si le fichier existe déjà, il est d'abord effacé;
    • 'a' {append} ouvre un fichier pour l'écriture à la suite des données déjà contenues dans le fichier. Si le fichier n'existe pas, il est alors créé.

fclose

fclose(fid)

Cette fonction ferme le fichier identifié par la variable fid.

  • fclose('all') permet de fermer tous les fichiers. Lors de la mise au point d'un programme, c'est une instruction à retenir et à écrire directement dans la fenêtre de Matlab ou au début du programme.
