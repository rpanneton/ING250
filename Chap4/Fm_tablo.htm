Affichage d'un tableau ayant différents types de données

Le fichier etoile0.m contient la définition de magnitudes et de distances de plusieurs étoiles.

%Fichier etoile0.m
clear
Etoile=[
'Sirius';'Altair';'Pollux';'Becrux';'Castor'
'Adhara';'Alioth';'Shaula';'Alkaid';'Alhena'];
Magnitude=[-1.42; 0.77; 1.16; 1.28; 1.58
            1.63; 1.68; 1.71; 1.91; 1.92];
Distance =[  8.7;   16;   33;  500;   47
             330;   49;  200;  190;   78];

Le fichier etoile1.m permet d'effectuer l'affichage de ces données de types différents.

% Fichier etoile1.m
clear
etoile0
n=length(Distance);
fid=1;	%écran
for i=1:n
   fprintf(fid,'%s %5.1f %5.2f\n',...
      Etoile(i,:),Distance(i),Magnitude(i));
end

  • le gabarit spécifie un champ minimal pour l'écriture;
  • un point sépare le gabarit de la spécification du nombre de chiffres après le point décimal;
  • on aligne à droite du champ spécifié par le gabarit; on peut aligner à gauche en écrivant le symbole {-} au début du code de format;
  • les caractères (y compris les espaces) ajoutés entre les codes de format sont affichés;
  • un signe {+} fait en sorte que le signe {+ ou -} soit toujours présent;
  • un zéro {0} fait précéder de zéro toute valeur non nulle.
