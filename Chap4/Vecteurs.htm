Vecteurs – tableaux 1D

Les vecteurs forment une structure de données fréquente à tous les langages de programmation, exemple :

  • Vecteur numérique : A = [ 10, 13, 23, 14 15 ]
  • Chaîne de caractères : B = 'C''est une histoire très courte.'
  • Vecteur booléen : A > 14, soit [0 0 1 0 1], spécifique à Matlab.

Le vecteur forme un tableau à une dimension. Chaque élément de A est identifié par un indice. « A et B » sont des variables indicée. Ainsi A(2) contient la valeur 13 et B(2) contient une apostrophe.

L'utilisation de tableaux implique presque toujours la lecture et l'écriture d'une quantité importante de données. C'est pourquoi le chapitre débute par des fonctions pour manipuler les différents types de données pour l'affichage à l'écran.

La lecture de données est une opération délicate, quel que soit le langage de programmation utilisé. Il est préférable d'utiliser des fonctions spécialisées comme load et xlsread.
