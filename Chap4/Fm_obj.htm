Introduction

Dans la plupart des langages de programmation, pour lire ou écrire des données dans des fichiers, on procède de la manière suivante :

  • Ouverture du fichier (fopen, file open) en spécifiant des attributs tels :
    • lecture seulement (r, read only),
    • écriture seulement (w, write only)
    • écriture après les données déjà contenues dans le fichier (a, append), etc.
  • Boucle contenant une instruction d'écriture (fprintf) ou de lecture des données en spécifiant des protocoles de conversion selon le type de données, tels
    • des entiers (%d digits),
    • des réels (%f, float),
    • des chaînes de caractères (%s, string), etc.
  • Fermeture du fichier (fclose, file close).

Par ailleurs, Matlab possède des fonctions permettant d'accomplir automatiquement ces opérations comme load(nom_du_fichier) et save(nom_du_fichier). Elles sont présentées dans la section portant sur les boucles.

Objectifs

  • Utiliser fprintf pour afficher à l'écran.
  • Lire ou écrire dans un fichier une combinaison de nombres et de caractères.
  • Afficher les matrices de façon plus soignée que la manière par défaut de Matlab.
  • Étudier le comportement des principaux formats : %d, %f, %s.

Fonction d'écriture fprintf

Un programme doit communiquer des résultats pour présenter un intérêt pratique. La plupart des langages de programmation possèdent une fonction similaire à fprintf pour l'affichage et l'archivage de différents types de fichiers dans des fichiers. C'est ce qui rend son étude pertinente dans le curriculum du cours.

La fonction disp est limitée

Les instructions disp, format, nom_de_variable_sans_point_virgule déjà présentées sont efficaces, mais ont des possibilités esthétiques limitées, et il est difficile d'afficher plus d'un type de données sans recourir à des artifices.
Exemple :

  • Supposer X1 = 74.2 et X2 = 7.8 :
    • disp('Les moyennes des examens sont :')
      X1
      X2
  • Résultat :
    • Les moyennes des examens sont :
      X1 =
         74.2000
      X2 =
          7.8000
  • Les valeurs sont présentées sans plus.

    La fonction num2str permet de transformer des données numériques en données caractères, ce qui rend possible un affichage plus élégant.

    • Texte='Les moyennes des examens sont ';
      disp([Texte,num2str(X1,3),' et ',num2str(X2,2)])
  • ce qui donne un affichage plus naturel :
    • Les moyennes des examens sont 74.2 et 7.8

Cependant, ces fonctions ne peuvent pas offrir un moyen de communication toujours adéquat. De plus, elles ne peuvent pas être utilisées pour communiquer avec des périphériques de communication, archiver ou lire des données dans les fichiers.

Comparaison de fprintf avec disp

Abréviation anglaise de file-print-formated, soit écriture formatée dans un fichier, la fonction fprintf  permet d'afficher toutes les combinaisons de valeurs.
Exemple :

  • X1=74.2;
chaine='La moyenne est ';
disp([chaine,num2str(X1,3)])
    donne : La moyenne est 74.2
 
  • fprintf('%s%4.1f\n',chaine,X1);
    donne : La moyenne est 74.2

Explications :

  • num2str(X1,3) : transforme un nombre en caractères;
    • une précision de 3 chiffres est spécifiée;
    • disp affiche uniquement des données caractères.
  • frprintf est une fonction d'affichage comportant plusieurs arguments :
    • la chaîne de caractères à l'intérieur de fprintf est appelée le format;
    • chaine et  X1 sont les variables à afficher.

Le format '%s%4.1f\n'

  • « % » début d'un code de format,
    • %s affichage d'une donnée constituée d'une chaîne de caractères (string) dont la longueur est indéterminée.
  • %4.1f
    • 4 :  un champ de 4 colonnes est réservé pour l'affichage,
    • .1 : écrire 1 chiffre après le point décimal,
    • f :  écrire la donnée en point flottant (float).

Description de fprintf

Il y a trois arguments différents dans la fonction, que l'on peut résumer ainsi :
fprintf(où, comment, quoi) :

  • où : variable spécifiant le périphérique;
    • Lorsque la variable = 1, elle spécifie l'écran comme périphérique. Dans ce cas, il n'est pas nécessaire de l'indiquer;
  • comment : chaîne de caractères qui précise la manière d'écrire les données;
  • quoi : indique les données à écrire.

Exemple :

  • X1=74.2;
chaine='La moyenne est ';
fid=1;
fprintf(fid,'%s%4.1f\n',chaine,X1);
    donne : La moyenne est 74.2
  • Lorsqu'on affiche à l'écran, il n'est pas nécessaire de spécifier un périphérique.
  • X1=74.2;
chaine='La moyenne est ';
fprintf('%s%4.1f\n',chaine,X1);
    donne : La moyenne est 74.2

Le deuxième argument de fprintf est appelé le format. Il est constitué d'une chaîne de caractères que l'on place entre apostrophes et qui contient un libellé et des codes. Ces codes de format débutent par le symbole % qu'il faut éviter de confondre avec un commentaire. Il existe différents codes permettant d'afficher des variables de type différent. Noter que l'instruction Matlab  format spécifie la manière par défaut d'afficher une variable_sans_point_virgule. Ce concept est différent du format de fprintf.

  • Les codes de format peuvent aussi être considérés comme des codes de conversion. Une donnée dans la mémoire de l'ordinateur est convertie pour affichage  : 
    • >> A = 82;
>> fprintf('%d\n',A)
82
    • >> fprintf('%f\n',A)
82.000000
    • >> fprintf('%e\n',A)
8.200000e+001
    • >> fprintf('%s\n',A)
R
    • Noter que «1» n'est pas nécessaire :
>> fprintf('%s\n',A)
R
  • La variable A, qui contient la valeur 82, est affichée respectivement comme un nombre entier, un nombre réel en notation décimale, un nombre réel en notation exponentielle et une notation pour une donnée de type caractère (R est le caractère no 82 en ASCII).

Codes de format les plus utiles

  • %d : valeur numérique entière (digit)
  • %f : valeur numérique réelle (float)
  • %e : valeur numérique réelle affichée en notation exponentielle
  • %g : valeur numérique réelle affichée en point flottant ou en notation exponentielle selon sa grandeur
  • %s : chaîne de caractères
  • \n : passer à la ligne suivante
  • Informations supplémentaires : >> doc fprintf

On peut spécifier un gabarit (souvent appelé le champ) ainsi qu'une précision dans un code format, par exemple :

  • >> disp('123456789') % Pour indiquer le no des colonnes
>> fprintf('%8.2f\n',45.857)

  • 123456789
   45.86
  • {%} indique le début d'un code format.
    • {8} spécifie le gabarit, c'est-à-dire le nombre de colonnes minimales (espace) réservées pour l'écriture.
    • {.2} détermine la précision requise, soit le nombre de chiffres souhaités après le point décimal.
    • {f} stipule l'utilisation d'une notation décimale comme code du format.
    • Les caractères {\n} entraînent le passage à la ligne suivante lors de l'exécution (nouvelle ligne).

Le format est vectorisé, c'est-à-dire qu'il est répété selon le nombre de données à écrire. C'est également le cas en Fortran, mais noter que ce n'est pas le cas dans le langage C.
Exemple :

  • >> fprintf('%8.2f\n',45.857,305.,0.37)
   45.86
  305.00
    0.37
>> 
  • >> fprintf('%8.2f %5.1f\n',45.857,305.,0.37)
   45.86 305.0
    0.37 >>
  • L'invite de Matlab est demeurée après 0.37, car il n'y a pas de \n après le troisième terme (%8.2f).
     
  • Note : fprintf est également une instruction en  C + +, mais dans ce langage, le format n'est pas vectorisé et il est d'un usage capricieux. De toute façon, l'instruction d'écriture normale en  C + + est  cout.

Si le nombre de données à écrire est inférieur au nombre de codes de format, les codes sont tout simplement ignorés. Exemple :

  • >> fprintf('%8.2f %5.1f\n',45.857)
   45.86 >>
