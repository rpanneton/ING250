Quatre caractéristiques d'un langage de programmation

Système de signes graphiques

Nous avons l'habitude d'utiliser plusieurs manières de noter ou de représenter des concepts par des symboles : notation des nombres, notation algébrique, notation atomique (Al, Cu), notation musicale pour représenter des sons, etc. Un langage de programmation est constitué de notations.

Moyen de communication

Il constitue une manière de représenter des idées abstraites en programmes. Par analogie, la langue française permet de réaliser des textes, des compositions, des romans, des lettres et de les communiquer aux autres humains. Elle a deux fonctions essentielles, l'expression et la communication.

Traduction des instructions à l'ordinateur

Les langages de programmation traduisent les notations du programme à l'ordinateur. Cette tâche est effectuée par un compilateur ou un interprète. Voir la section «Matériel et Logiciel».

Organisation des parties de programme

Le langage offre des outils pour permettre une organisation adéquate des différentes parties d'un programme. C'est le sujet de la section «Écriture et style du code».

Paradigmes de langages informatiques

Les langages de programmation sont regroupés selon plusieurs paradigmes (modèles).

Programmation impérative

La programmation est vue comme une séquence d'actions. Les langages issus de ce modèle sont souvent appelés langages procéduraux. Exemples : Fortran (1954, 1957, 1966, 1977, 1990, 1995, 2000), Pascal (1971) et C (1972). Référence : Qa76.73

Programmation orientée objet

Ce paradigme tire son origine du langage Simula (1961-1966), qui est à la fois un langage de description et un langage de programmation. Les classes d'objets constituent le concept principal de ce langage de simulation. On retrouve principalement des langages tels que

  • Smalltalk, système interactif avec une interface graphique,
  • C + +, qui ajoute une coquille objet au langage impératif C,
  • Ada, 1983 et 1995.

Autres paradigmes

Il y a bien d'autres, par exemple,

  • la programmation fonctionnelle, dont le Lisp, utilisé dans des programmes d'intelligence artificielle,
  • la programmation logique, dont Prolog, développé par Alain Colerauer et Philippe Roussel (Montréal, 1972); ce langage est souvent utilisé pour la rédaction de bases de données et de systèmes experts.

Référence

Parmi les nombreux traités sur les langages de programmation, les manuels suivants présentent les principales caractéristiques des langages :

  • Pratt, T.W, Zelkowitz, M.V., Programming Languages, Prentice Hall, QA76.7 P7.
  • Sethi, R., Programming Languages, Addison-Weley, Qa76.7.S48

Trois composants définissent les langages procéduraux

Les langages procéduraux diffèrent seulement dans le type de données autorisées, dans la nature des opérations disponibles et dans les mécanismes proposés pour contrôler l'ordonnancement dans lequel les opérations doivent être appliquées aux données. Les trois composants, données, opérateurs et mécanismes de contrôle, forment la base de la programmation et définissent le cadre des langages informatiques.

  • Les données représentent les unités d'information telles qu'un nombre ou un caractère. Bien qu'un ordinateur traite toutes sortes d'informations, il manipule que des bits {0,1}. En d'autres termes, un ordinateur ne sait traiter que des chiffres et il traduit donc toute information en un code numérique.
  • Les opérateurs {+}, {-}, {*}, {/}, {^}, {.*}, {./}, {.^} permettent de réaliser des opérations élémentaires sur des données numériques.
  • Quant aux mécanismes de contrôle, ils permettent de gérer l'ordre de la séquence des instructions d'un programme; ce sont les structures de décision et les boucles.

Donnée variable et objet

Comme les opérateurs et les mécanismes de contrôle sont traités dans les chapitres précédents, cette section se penche sur les données.

Propriétés d'une variable

 En programmation, chaque variable possède 4 propriétés : elle a un nom, elle appartient à un type (classe), elle occupe un espace physique en mémoire et elle contient une valeur.

  • Nom.
    • En attribuant un nom à une donnée, elle devient une variable.
    • Une variable Matlab débute par une lettre qui peut être suivie d'autres lettres choisies parmi les 26 lettres de l'alphabet, de chiffres ou du caractère de soulignement { _ }; cet ensemble constitue les caractères alphanumériques. Les caractères accentués {é, è, ê} ne sont pas acceptés.
    • Le nom d'une variable Matlab comporte jusqu'à 31 caractères Matlab 6,1) ou 63 (Matlab 6.5); Matlab ignore les caractères qui dépassent ce nombre.
    • Matlab fait une distinction entre les lettres minuscules et les lettres majuscules. Mais ne pas créer de variables dont les noms ne diffèrent que par la capitalisation.
    • Comme les noms de variables font partie de la documentation d'un programme, utiliser des noms significatifs. Exemple : distance au lieu de «d».
  • Type et classe
    • Ils déterminent la sorte de données. 
    • Les types de base classiques tels entier, réel, caractère, logique (booléen) font partie habituellement de l'arsenal des langages de programmation.
    • Dans la mémoire de l'ordinateur, la représentation interne des données est spécifique à chacun des types de données.
    • Matlab implémente les types sous la forme de classes.
      • La classe est un type construit à partir d'autres classes ou d'autres types.
        Exemple : la classe symbolique utilise le type caractères pour décrire des objets symboliques.
  • Espace physique
    • Le nom représente l'adresse de la donnée, soit la localisation dans la mémoire de l'ordinateur. Il n'est pas possible d'accéder directement à l'adresse avec Matlab.
       
  • Valeur
    • Le nom permet d'accéder à la valeur de la donnée pour l'utiliser ou la modifier.
Objet et méthode

Plutôt que d'utiliser de simples variables, Matlab utilise le concept d'objets créés à partir de classes pour contenir les données.

  • Une variable est une instance {signifie une création} d'un type de base tandis qu'un objet est une instance d'une classe.
  • La classe contient des opérateurs et des fonctions spécifiques aux objets appartenant à cette classe, le tout d'une manière conviviale et transparente. Dans le paradigme objet, la fonction spécifique à une classe est appelée une méthode.

Exemple : opérateur plus (+)

L'opérateur d'addition {+} opère de façon transparente avec des objets de la classe double et des objets de la classe sym.

Pour accomplir ceci, Matlab définit deux opérateurs différents :

  • un opérateur {+} pour des objets de la classe double
  • et un autre pour la classe sym.
>> z = 3 + cos(pi/4)
z =  -2.2929
>> f = sym('-x');
>> g = sym('cos(x)');
>> y = f + g
y =  -x+cos(x)
>> whos
  Name  Size  Bytes  Class
  f      1x1    126  sym object
  g      1x1    136  sym object
  y      1x1    140  sym object
  z      1x1      8  double array

Des fonctions différentes ou méthodes sont associées à chacune des classes et permettent de manipuler les objets appartenant à leur classe.

>> help plus
    X + Y adds matrices X and Y, etc.
>> help sym/plus
 PLUS   Symbolic addition.
    PLUS(A,B) overloads symbolic A + B.
>> help cos
    COS(X) is the cosine of the elements of X.
>> help sym/cos
 COS    Symbolic cosine function.

Il y a deux méthodes pour l'opérateur «+» ainsi que pour le calcul du cosinus.
