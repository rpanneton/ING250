Tracer des surfaces 3D

Référence : Chap5\Tracer

  • Surfaces réelles comme dans le domaine de l'automobile ou de l'aéronautique
    • Elles sont construites à partir de coordonnées de points en 3D
      >> doc patch
    • Exemple :
      Reprise d'une portion du projet S1 de la 48e.
      • Velodrom.ppt : plan du vélodrome installé à Bromont
      • Velodrom.xls : mesures 3D effectuées sur la piste
      • Velo1.m : tracé du vélodrome en 2D
      • Velo2.m : tracé 3D, on peut déplacer la figure dans les 3 axes pour l'examiner.
  • Surfaces paramétrées
    • Elles sont construites à partir d'équations connues (plutôt que de points) :
      >> doc surf
