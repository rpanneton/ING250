Concept de vecteur en informatique

Avant-propos

Dans la plupart des langages de programmation, le vecteur est une structure de données appelée tableau à une dimension (array). C'est une variable indicée (à un indice).

La liste des températures moyennes journalières pendant une semaine constitue un bel exemple de données à regrouper dans un vecteur Matlab :
21, 22, 19, 20, 24, 28, 27

Au lieu d'écrire
   Jour1 = 21, Jour2 = 22, Jour3 = 19, Jour4 = 20,
   Jour5 = 24, Jour6 = 28, Jour7 = 27,
un tableau à une dimension permet de regrouper les données :

>> Jour = [21, 22, 19, 20, 24, 28, 27]

  • L'exemple précédent constitue un vecteur ligne ou tableau à une dimension.
  • Les éléments sont écrits entre une paire de crochets.
  • Tous les éléments sont regroupés sous un même nom (Jour)
  • Chaque élément du vecteur Jour est identifiable par un indice.
    Ainsi Jour(1) contient la valeur 21 et Jour(7) contient 27.
  • Jour est une variable indicée, exemple d'indice : 1 et 7.
>> clear all
>> Jour = [21, 22, 19, 20, 24, 28, 27]
Jour =
    21    22    19    20    24    28    27
>> Jour(1)
ans =
    21
>> Jour(7)
ans =
    27

On peut générer un vecteur colonne en séparant chaque élément par un point-virgule.

>> y = [10;20;30]
y =
    10
    20
    30

Tableau 1D ou vecteur

Un tableau à une dimension est appelé aussi vecteur par analogie avec l'objet mathématique.

Vecteur

Structure de données contenant une succession de plusieurs éléments de la même classe. Matlab permet de représenter un vecteur ligne ou un vecteur colonne.

Reproduire les exemples proposés, car l'habileté à programmer s'acquiert par une pratique régulière. Lire ne suffit pas, ni une boulimie d'étude de dernière minute.

 

Écrire un vecteur colonne

Soit le vecteur :

On écrit un vecteur entre crochets et les données d'un vecteur colonne sont séparées par un point-virgule :
>> clear all;
>> u=[3;-1;-2]
Matlab affiche aussitôt le résultat de l'instruction précédente à l'écran; il effectue l'écho des données :
u =
     3
    -1
    -2

Il est possible d'écrire une donnée par ligne :
>> u = [ <entrée>
3 <entrée>
-1 <entrée>
-2 <entrée>
] <entrée>
 
Quelle est la meilleure façon ?  Habituellement la forme avec points-virgules est plus commode et se prête facilement à des modifications sans devoir écrire cinq lignes :
  >> u=[3;-1;-2] <entrée>

Continuer l'exercice :

 
  >> v=[-2;5;1]
  >> w=[-4;-4;1]

Écrire une matrice

Comme Matlab range en mémoire toutes les données sous la forme de tableaux, il est nécessaire de présenter le concept de matrice, afin d'interpréter correctement les messages d'erreur générés pendant l'exécution.

  • Une matrice est une structure de données comportant n rangées et m colonnes.

  • L'instruction size(matrice) fournit la dimension du tableau.
  • On peut écrire la matrice sur une seule ligne, mais c'est moins intuitif : 
·       >> matrice=[11 12 13;21 22 23;31 32 33]
·       matrice =
·           11    12    13
·           21    22    23
    31    32    33
 

Accès aux éléments d'un vecteur

Pour accéder à un élément d'un vecteur, il suffit d'écrire le nom du vecteur, suivi du numéro de l'élément entre parenthèses. La numérotation débute par le chiffre 1 :

>> x = [11 12 13]
x =
    11    12    13
>> y = [10;20;30]
y =
    10
    20
    30
>> x(2) % 2e élément de x
ans =
    12
>> y(3) % 3e élément de y
ans =
    30
>> x(1)+ y(1)
ans =
    21
>> x(1)=99 % une valeur est modifiée.
x =
    99    12    13

Variable indicée, size, length

Le nombre entre parenthèses est l'indice de la variable. C'est pourquoi un tableau est aussi appelé variable indicée. On accède aux différentes valeurs de la variable en spécifiant un indice. La dimension de la variable représente le nombre d'éléments qu'elle contient :

>> size(x)
ans =
     1     3     % 1 ligne, 3 colonnes
>> size(y)
ans =
     3     1     % 3 lignes, 1 colonne
>> length(x)
ans =
     3
>> length(y)
ans =
     3

Les fonctions size et length fournissent les dimensions des variables indicées x et y. Pour obtenir de l'aide sur une fonction :

>> doc length
>> doc size

Révision

>> clear all
>> Jour = [21, 22, 19, 20, 24, 28, 27]
Jour =
    21    22    19    20    24    28    27
>> whos
  Name      Size
  Jour      1x7

Jour est contenu dans la mémoire de Matlab comme une matrice ayant une ligne par 7 colonnes :

>> [n,m] = size(Jour)
n =
     1
m =
     7
>> nElementsDuVecteur = length(Jour)
nElementsDuVecteur =
     7

Dernier item de jour :

>> Jour(end)
ans = 
     27

Une variable ne contenant qu'une valeur est aussi conservée sous la forme d'une matrice :

>> clear all
>> A = 3.2
A =
          3.2
>> whos A
  Name      Size            Bytes  Class     Attributes
 
  A         1x1                 8  double      

La variable A est une matrice d'une ligne par une colonne.

 

Le concept informatique de vecteur est utilisé pour résoudre des problèmes impliquant des vecteurs en statique. Bien distinguer les deux concepts.
