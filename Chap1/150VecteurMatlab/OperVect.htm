Opérateurs vectoriels

Mise en contexte

Pour obtenir le vecteur R résultant de la somme des vecteurs F1 et F2, il faut additionner séparément chacun des éléments (ou composantes) :

>> F1 = [1,2], F2 = [3,1]
F1 =       1     2
F2 =       3     1
>> F1(1) % 1er élément de F1
ans =      1
>> F1(2) % 2e élément de F1
ans =      2
>> R(1) = F1(1) + F2(1)
R =        4
>> R(2) = F1(2) + F2(2)
R =        4     3

Opérateur vectoriel +

Matlab permet d'effectuer directement des opérations élément par élément entre des vecteurs :

>> F1 = [1,2], F2 = [3,1]
F1 =     1     2
F2 =     3     1
>> R = F1+F2
R =      4     3

Il n'est donc pas nécessaire d'effectuer séparément l'addition de chacun des éléments. Matlab le fait automatiquement. Le symbole + signifie une addition scalaire ainsi qu'une addition élément par élément d'un tableau. C'est un opérateur vectoriel.

Opérateurs arithmétiques habituels

Ajout d'un scalaire :

>> F1 = [1,2]
F1 =      1     2
>> G = 3 + F1
G =       4     5

Soustraction d'un scalaire :

>> F2
F2 =     3     1
>> H = F2 - 2
H =      1    -1

La multiplication ou la division d'un vecteur par un scalaire est une opération ordinaire :

>> A = [4 5 6]
A =      4     5     6
>> B = A*3
B =     12    15    18
>> C = B/3
C =      4     5     6

Multiplication de deux vecteurs

La multiplication d'un vecteur par un autre vecteur doit respecter l'algèbre matricielle :

>> A * B
??? Error using ==> mtimes
Inner matrix dimensions must agree.

Le vecteur ligne (matrice 1×3) doit être multiplié par un vecteur colonne  (matrice 3×1) :

>> A * B' % B' est la transposée de B.
ans =    231
>> soit = A(1)*B(1) + A(2)*B(2) + A(3)*B(3)
soit =    231

Pour multiplier composante par composante, il faut les multiplier élément par élément :

>> C = [A(1)*B(1), A(2)*B(2), A(3)*B(3)]
C =
    48    75   108

L'opérateur vectoriel « .* » permet de le faire automatiquement :

>> C = A .* B
C =
    48    75   108

L'opérateur « .* » comporte deux symboles et indique la multiplication élément par élément entre deux vecteurs (ou deux matrices).

Opérations élément par élément

« .* »  multiplication élément par élément

« ./ »  division élément par élément

« .^ »  élever à la puissance élément par élément

Noter qu'il y a deux symboles pour UN opérateur et qu'ils ne doivent pas être séparés par un espace :

>> D = [5 8 4]
D =
     5     8     4
>> P = [ 1 2 3]
P =
     1     2     3
>> D .* P
ans =
     5    16    12
>> D ./ P
ans =
     5     4     1.3333
 
>> D .^ P
ans =
     5    64    64

Contre - exemple

Élever au carré chacun des éléments du vecteur D :

>> D = [5 8 4]
D =
     5     8     4
>> D^2
??? Error using ==> mpower
Matrix must be square.
 
>> % Il faut plutôt écrire :
>> D.^2
ans =
    25    64    16

On peut obtenir de l'information sur une fonction Matlab en écrivant :
>> doc arith
>> docsearch('Arithmetic Operators')
>> help *
>> help /
etc.
