Instructions pour l'utilisation du tutoriel

Pour utiliser le tutoriel Introduction à Windows 95, il faut copier tous les fichiers dans un répertoire; supposons que ce soit {c:\Ing250\win_intr\}

Contenu des fichiers \win_intr\*.*

  • Exception faite du préambule, le fichier menu.htm relie directement tous les autres incluant les notes explicatives du glossaire.
  • Le fichier Exercice.txt contient le texte d'un exercice à faire avec l'éditeur de texte PFE.
  • Tous les fichiers d'images {*.jpg ou *.gif} sont contenus dans le répertoire contenant les fichier {*.htm}.
  • Deux dossiers (répertoires) Fenêtre_Abc et Fenêtre_Xyz sont utilisés pour les exercices. Ils sont rangés ici afin que l'ensemble soit complet pour une copie éventuelle destinée à être utilisée ailleurs qu'à la Faculté.
  • Tous les liens hypertextes sont relatifs. On peut simplement copier le contenu de {\win_intr\*.*} dans le dossier de son choix. On n'a pas besoin d'accéder au réseau Internet.
  • L'item Aller au menu général de {menu.htm} se rallie à {..\sca.htm}; c'est le seul fichier situé à l'extérieur du répertoire {\win_intr}.
  • On visualise le logiciel grâce au logiciel Netscape dont on peut obtenir la copie sur le serveur Clio ou Tiffany.

Configuration du bureau

Sur le bureau, il doit y avoir:

  1. l'arrangement Novel (disque J:, H: et C:);
  2. une fenêtre Netscape à droite de l'écran et occupant les ¾ de l'écran;
  3. on extrait de \win_intr\ les deux dossiers contenant les fenêtres Abc et Xyz que l'on place sur le bureau;
  4. la fenêtre Abc déborde légèrement à gauche de la fenêtre Netscape; on doit en apercevoir le titre. La fenêtre Xyz est placée en dessous de la fenêtre Netscape de façon à être invisible;
  5. l'utilitaire Aide de Windows doit être configuré pour être toujours visible (via le Menu Option).

Où débuter?

  • Initier les étudiants avec {\win_intr\pre1.htm}. Ce préambule est destiné au novice, mais une note explicative permet aux autres d'atteindre rapidement le menu.
