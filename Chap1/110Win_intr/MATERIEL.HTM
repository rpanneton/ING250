Caractéristiques du matériel

Le fichier Msinfo32.exe (un programme binaire) affiche certaines caractéristiques du matériel que vous utilisez en ce moment. Nous en profitons pour illustrer comment rechercher un fichier lorsque l'on ne sait pas dans quel répertoire le trouver.

Exercice

  • Cliquer sur le bouton Démarrer
  • Choisir successivement les items
    Rechercher
    Fichiers ou dossiers
    Une fenêtre apparaît.
  • Rubrique {Nommé} écrire Msinfo32.exe
    Rubrique {Rechercher dans} choisir le disque (C:), correspond habituellement au disque dur de votre station de travail.
    Windows va rechercher le fichier pour vous. Lorsqu'il le trouve, cliquer deux fois sur le nom du fichier; Windows va lancer l'application.
