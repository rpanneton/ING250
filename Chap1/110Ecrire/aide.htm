doc

·       Ouvre le guide d’utilisation dans le fureteur.

·       On peut l’appelle depuis la ligne de commande

>> doc

·       On peut l’ouvrir directement sur un élément spécifique afin d’obtenir une information plus détaillée que celle obtenue avec help

>> doc cos

Soyez curieux !

« Amusez-vous » à explorer la documentation de Matlab.  N’hésitez pas!

Avant de demander à l’enseignant, tenter de répondre par vous-mêmes à votre question à l’aide de « help » et de « doc ».

Noter que pendant les évaluations, vous n’aurez pas le droit aux notes de cours.  

Par contre, vous aurez accès à « help » et « doc ».  Donc, utilisez-les le plus souvent pour vous y habituer!
