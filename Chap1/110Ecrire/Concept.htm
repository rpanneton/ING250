Séquences d’instructions

Les instructions que l'on écrit dans la fenêtre Matlab s'exécutent au fur et à mesure de leur écriture, de façon séquentielle. Écrire la séquence d'instructions suivantes :

  • effacer la mémoire de Matlab à l'aide de l'instruction
    >> clear
  • créer la variable réelle portant le nom Prix en lui donnant la valeur 25.04
  • calculer la valeur de la variable nommée TPS valant 0.05 du Prix (5 %)
  • calculer la valeur de la variable nommée TVQ valant 7.5 % du Prix incluant la TPS
  • ajouter la TVQ au PrixTotal et mettre à jour la variable PrixTotal en tenant compte de la TVQ
    • noter qu'il n'y a pas d'espace entre le mot Prix et total
    • une variable ne peut pas comporter d'espace, c'est pourquoi nous avons utilisé PrixTotal. Vous pouvez aussi appeler la variable Prix_total vec le caractère souligné, c'est votre préférence

Types ou classes des variables (taper whos à l’invite de commande):

  • Size est la dimension (n x m) du tableau représentant la variable (ici 1x1 indique un scalaire)
  • Bytes est le nombre d’octets utilisés pour représenter la variable
    • 1 byte est 1 octet, lequel contient 8 bits
    • 1 bit = le chiffre 0 ou 1
  • Class est la classe de la variable
    • double signifie un tableau représentants des nombres
    • La classe double représente un nombre en utilisant 8 octets, soit 64 bits de mémoire selon la norme des fabricants  IEEE  754.

Touches pour répéter une instruction

Les touches {flèche vers le haut} et {flèche vers le bas} permettent de rappeler une instruction Matlab sans avoir à taper de nouveau l'instruction.

Plutôt que d'appuyer à répétition pour afficher une instruction que l'on a écrite 10 ou 15 instructions auparavant, écrire la première lettre, puis appuyer sur la touche {flèche vers le haut}.

Par exemple :

·       à l’invite de commande, taper T  (>> T)

·       puis taper sur la {flèche vers le haut}

·       la dernière instruction commançant par T apparaîtra

·       en cliquant encore sur la {flèche vers le haut}, vous monterez dans l’historique

·       en cliquant encore sur la {flèche vers le bas}, vous descendrez dans l’historique

Conclusion 

Dans le mode interactif, les instructions s'exécutent les unes à la suite des autres, de façon séquentielle comme dans une calculatrice.

Ce n’est pas pratique quand on fait beaucoup de calculs avec des variables qui peuvent changer de valeurs et influencer les autres.

Dans ce cas, on préfèrera le mode de programmation de script ou fonction.
