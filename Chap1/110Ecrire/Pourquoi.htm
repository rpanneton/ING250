Instructions écrites directement dans la fenêtre

Comme nous avons vu précédemment, dans le mode interactif de Matlab, lorsqu'on tape une instruction, Matlab répond immédiatement et attend la prochaine instruction. Il agit comme une calculatrice.

Programme (ou script dans le langage Matlab)

Un programme est un regroupement d'instructions dans un fichier dont le suffixe se termine par « m ». L'exécution d'un programme fait exécuter automatiquement les instructions qu'il contient.

Ces instructions sont écrites dans la fenêtre de Matlab. Matlab répond immédiatement après chacune des instructions.

Pour une nouvelle valeur de prix, il faut faire exécuter à nouveau toutes les instructions de façon séquentielle.

Ce que l'on veut faire, c'est écrire un nouveau Prix et faire exécuter automatiquement les trois instructions requises pour obtenir la valeur de PrixTotal.

Matlab offre cette souplesse en permettant de regrouper ces instructions dans un fichier et de les faire exécuter sur demande.

En résumé, un script est un fichier se terminant par .m et contenant des instructions que Matlab exécute l'une après l'autre lorsqu'on écrit le nom de ce fichier dans Matlab.

 

L'éditeur d'instructions

Écrire dans la fenêtre Matlab

>> edit   (et non pas édite)

L’éditeur s’ouvre dans une sous-fenêtre.   

Écrire les instructions contenues dans l'illustration.

  • Le symbole {%} est utilisé pour écrire un commentaire. Matlab interprète que ce n'est pas une instruction exécutable.  L'éditeur affiche automatiquement les commentaires en vert.
     
  • Au début du fichier, il est d'usage de décrire la tâche du programme. Ainsi, lorsqu'on utilise la commande help {nom}, Matlab affiche toutes les lignes débutant par le symbole {%}, depuis le début du fichier jusqu'à la première ligne d'instruction. Cela fournit une courte description du programme.
     
  • Aucune variable Matlab ne doit être accentuée. C'est une norme courante dans la plupart des langages de programmation.
     
  • Le symbole { * } dans le titre de la fenêtre indique que des modifications ont été apportées dans le texte contenu dans l'éditeur et qu'elles n'ont pas été sauvegardées.
     
  • Lorsque vous avez terminé, faire une sauvegarde dans le répertoire de travail sous le nom de taxe1.m (en lettres minuscules). Une façon rapide est de cliquer sur l'icône disquette dans la barre des menus de l'éditeur.



Remarquer le nom du fichier dans le titre de la fenêtre et l'absence du symbole * après le mot taxe1*.

Examiner les résultats des instructions suivantes :

  • L'instruction help affiche les commentaires contenus dans le fichier taxe1 jusqu'à la première instruction exécutable.
  • Le Prix est défini de façon interactive dans la fenêtre Matlab.
  • L'instruction taxe1 fait exécuter le fichier taxe1.m.
  • Si vous tapez « prix » au lieu de « Prix », taxe1 produit une erreur, car Prix n'est pas défini. Matlab tient compte de la case des lettres.

NOTE IMPORTANTE : 

·       Apprenez à lire les erreurs renvoyées par MATLAB. 

·       Elles sont écrites en rouge.

·       Elles vous renvoient, par hyperliens, à l’endroit où l’erreur est commise dans le script.

Expérimenter

Faire l'essai de votre script avec différentes valeurs de Prix; modifier le contenu des commentaires et autres. Expérimenter suffisamment pour comprendre qu'une sauvegarde est essentielle pour que les modifications apportées dans le fichier taxe1.m prennent effet. Les modifications apportées dans l'éditeur s'effectuent dans la mémoire de l'ordinateur et ne modifient pas le contenu du fichier conservé sur le disque. Une sauvegarde est requise pour écraser le fichier contenu sur le disque et le remplacer par le contenu de la fenêtre de l'éditeur.

La variable Prix et non pas prix doit être définie dans la fenêtre de Matlab avant de faire exécuter taxe1.

Voici quelques idées pour améliorer l'affichage à l'écran :

  • Utiliser l'instruction format pour modifier le nombre de chiffres significatifs Pour plus d'informations,
    >>     help format
  • Utiliser l'instruction disp (display) pour ajouter une ligne entre les différents essais. Écrire à la fin du script
         disp('-------------')
    Pour plus d'informations,
    >>     help disp
