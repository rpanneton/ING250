Gérer des fichiers à partir de la fenêtre de commande

Identifier le répertoire de travail

Le répertoire de travail, c'est celui dans lequel Matlab édite et exécute les fichiers *.m.
L'instruction  >> cd  permet d'obtenir le nom du répertoire de travail courant de Matlab.

 

Choisir un autre répertoire de travail

Pour changer de répertoire de travail, écrire
>> cd nom du répertoire.


>> help cd pour plus d'informations.

 

Obtenir la liste des fichiers d'un répertoire

L'instruction
>> dir
liste tous les fichiers du répertoire courant de Matlab.

 

Effacer un fichier

L'instruction delete nom du fichier
efface un fichier, ce qui évite de passer par l'intermédiaire de l'explorateur pour l'effacer.
