Définition

Le produit scalaire est défini ainsi :
A•B = AB cos θ

Deux points de vue :

  • C'est la norme du vecteur A multiplié par la composante (B cos θ) du vecteur B dans la direction de A.
  • C'est également la norme du vecteur B multiplié par la composante (A cos θ) du vecteur A dans la direction de B.

Le produit scalaire permet de calculer l'angle entre deux vecteurs.

Le produit scalaire est commutatif : A•B = B•A.

Corollaires

  • Les vecteurs A et B sont orthogonaux si leur produit scalaire vaut zéro :
    A•B = AB cos θ = 0
  • de plus, les vecteurs A et B sont aussi orthonormés si leur norme vaut 1 :
    sqrt(A•A) = sqrt(B•B) = 1.

Perspective géométrique

Il est possible de définir le produit scalaire sans faire appel à la définition du cosinus. Examiner le cas de trois points distincts O, A et B dans le plan. En projetant le segment OB sur OA et en appliquant le théorème de Pythagore, le produit scalaire de OA•OB est │OA│×│OC│en valeur absolue.

Comme le produit scalaire est commutatif, c'est-à-dire OA•OB = OB•OA,
de la même façon, en projetant OA sur OB, le produit scalaire de OB•OA est │OB│×│OD│en valeur absolue.

Lorsque le point O est entre A et B, le produit scalaire est négatif :
OA•OB est  − │OA│×│OE│en valeur absolue.

Calcul d'une projection

Le calcul d'une projection d'un vecteur sur un axe est une application intéressante du produit scalaire.

La projection Fn = F cos(θ) de F peut s'écrire comme F·n où n est un vecteur unitaire dans la direction donnée, comme sur la figure.

D'un point de vue général, la projection de F sur la direction n a comme composante rectangulaire scalaire Fn = F·n.

Pour exprimer la projection sous la forme d'une composante vectorielle, il suffit de multiplier la composante scalaire par le vecteur unitaire n,·
Fn n = F cos(θ) n =  F·n n.

La solution proposée illustre la manipulation des éléments de vecteur.

 
% Ex2a
clear all; clc
A = [+5 +3 -1];
B = [+3 -2 +1];
PS = A(1)*B(1) + A(2)*B(2) + A(3)*B(3)
NormeA = sqrt(A(1)^2 + A(2)^2 + A(3)^2)
NormeB = sqrt(B(1)^2 + B(2)^2 + B(3)^2)
cos_theta = PS / (NormeA*NormeB)
theta = acosd(cos_theta) % angle en degrés
